# UI-UX-Experiment5

## Aim:

To identify user pain points, develop UX problem statements, select suitable research methods, and create user personas for two different UX project scenarios.

## Algorithm:

1. Select two UX project scenarios.
2. Identify the target users and their needs.
3. Identify the major user pain points.
4. Develop suitable UX problem statements.
5. Select appropriate research methods.
6. Analyze the collected user information.
7. Create user personas based on the findings.
8. Identify user goals, behaviors, and motivations.
9. Suggest suitable UX solutions.
